# UTC ↔ IST Time Converter (GitHub Pages & APK-Ready PWA)

## Upload to GitHub (Flat Root — No Subfolders Needed)
1. Unzip this archive.
2. Upload **all files** (`index.html`, `styles.css`, `app.js`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `.nojekyll`) directly to the **root** of your GitHub repository.
3. Enable **Settings → Pages → Deploy from a branch (`main` / `root`)**.
4. Verify your icons load by opening `https://<username>.github.io/<repo>/icon-192.png` in your browser, then paste `https://<username>.github.io/<repo>/` into [PWABuilder](https://www.pwabuilder.com/) to generate your `.apk`.
